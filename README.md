# 合奏 Ensemble

> 五个声部，一个成品。

人机同群的 Agent 交付工作台。官方提供行业工作室，也可以从零搭一个。

## 页面

**主流程**

| 文件 | 说明 |
|---|---|
| `login.html` | 登录 / 注册：手机验证码、微信扫码、邮箱密码 |
| `studio.html` | 工作台：群列表 + 账户卡 + 群设置抽屉 |
| `chat.html` | 群聊：顶栏 / 消息 / 输入框，产物收进抽屉 |
| `builder.html` | 创建群聊：选模板、配成员、接渠道、实时预览 |

**辅助**

| 文件 | 说明 |
|---|---|
| `site.html` | 官网（滚动驱动动画） |
| `mobile.html` | 移动端四屏（营销素材） |
| `themes.html` | 四套主题对比（开发工具） |

`index.html` → 登录页，`home.html` → 工作台（旧链接兼容）。

## 交互

所有页面的按钮都能点。共用一套 `ui.js`（弹窗 / 轻提示，无依赖）：

| 位置 | 动作 |
|---|---|
| 工作台 · 邀请 | 弹窗给出邀请链接，可复制 |
| 工作台 · 群设置 · 解散 | 二次确认（红色按钮）→ 关闭抽屉 + 提示 |
| 工作台 · 接入飞书 | 三步配置说明 + Webhook 地址 |
| 工作台 · 账户设置 | 展示账户信息 |
| 工作台 · 空态模板 | 跳创建页 |
| 群聊 · 成员 | 弹窗列出 7 个成员 |
| 群聊 · 打回修改 | 二次确认 → 提示"工头重新拆解中" |
| 群聊 · 附件 | 提示支持的格式 |
| 群聊 · 空态提示 | 点一下就把示例指令填进输入框 |
| 群聊 · 产物文件 | 选中高亮 + 提示打开 |
| 创建页 · 移除成员 | 二次确认 → 删除该行 |
| 创建页 · 添加 Agent | 平台库 / 外部接入两种说明 |
| 创建页 · 创建 | 提示后跳转群聊 |
| 登录 · 条款 | 弹窗展示条款范围 |
| 官网 · 页脚 | ClawHunt / Agent 赛道 / 原型说明均有内容 |

未真正接后端的按钮（附件上传、外部 Agent 握手）点击后给出明确提示，不是无声无息。

演示快捷参数：

```
studio.html?open=invite    自动打开邀请弹窗
studio.html?open=feishu    自动打开飞书配置
```

## 页面状态

`studio.html` 支持参数演示三种状态：

```
?state=empty     空态：四个模板入口
?state=loading   骨架构屏
?state=error     加载失败 + 重试
```

`chat.html?state=empty` 是空群引导。

## 设计规范

**珠光 Pearl** —— 白纸、灰底、一个主色。

| Token | 值 | 用在哪 |
|---|---|---|
| `--bg-solid` | `#F3F4F7` | 页面底 |
| `--glass` | `rgba(255,255,255,.97)` | 卡片 |
| `--tx` | `#0D0D10` | 正文 |
| `--primary` | `#4F46E5 → #7C3AED` | 主按钮、进度、选中态、logo |
| `--success` | `#059669` | 运行中 |
| `--warning` | `#D97706` | 等你确认 |
| `--danger` | `#DC2626` | 风险、错误 |

**五个角色各有一色**，只在头像上用（11% 底 + 深字）：

工头琥珀 `#B45309` · 查证蓝 `#0369A1` · 撰写紫 `#6D28D9` · 审校红 `#B91C1C` · 交付绿 `#047857`

**尺寸**

- 导航：64px 高，1120 宽，40 内边距 —— 全站唯一一份 `.app-nav`
- 字号 7 档：11 / 12 / 13 / 14 / 16 / 20 / 28
- 圆角 3 档：8 / 12 / 16
- 间距：8 的倍数

## 官网动效

CSS scroll-driven animations（`animation-timeline`），不依赖 JS 动画库：

- Hero 标题逐行升起，产品图随滚动缩放淡出
- 每个区块进入视口时 fade + translateY
- 流水线从左侧生长
- 深色章节时导航自动反色

系统开启"减弱动态效果"时全部关闭。
